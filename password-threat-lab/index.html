      02 / Threat map

      Three different attack surfaces

      Conflating password guessing, Grover's algorithm, and Shor's algorithm produces misleading crack-time claims.

      Classical / password hashes

      Dictionary, mask, and brute-force attacks

      An attacker with an offline verifier tests likely choices and patterns first. The storage algorithm and cost settings can change throughput by many orders of magnitude.

      Target
      Password verifier
      Primary defense
      Unique length, blocklists, rate limits, costly salted hashing

      Quantum / symmetric search

      Grover's square-root query advantage

      Grover reduces an unstructured search from roughly N checks to roughly √N oracle queries. A query count is not a quantum clock: the verifier must be implemented reversibly and fault-tolerantly.

      Target
      Unstructured key or password search
      Shown here
      Random-space query proxy only

      Quantum / public-key cryptography

      Shor is the structural migration threat

      Shor attacks the mathematical problems behind widely deployed RSA and elliptic-curve systems. That is separate from directly guessing a stored password hash.

      Target
      Vulnerable key establishment and digital signatures
      Response
      Inventory, migration planning, and standardized PQC

      03 / Action

      What improves the real outcome

      A dramatic timer is less useful than controlling the attack path.

      01

      Use unique generated secrets

      Length and randomness defeat pattern-first guessing better than predictable composition substitutions.

      02

      Protect the verifier

      Apply rate limiting online and salted, costed password hashing for offline resistance.

      03

      Add phishing-resistant MFA

      Password length does not stop phishing, malware, session theft, or social engineering.

      04

      Manage cryptographic migration separately

      PQC planning belongs in the public-key inventory and protocol lifecycle, not inside a password meter.

      04 / Method

      Transparent assumptions

      This bounded educational model does not claim to reproduce Hashcat, zxcvbn, a breach corpus, or a fault-tolerant quantum resource estimate.

      Pattern-aware estimate

      The lowest-cost bundled strategy wins. Patterns include common values, basic leetspeak, word-plus-number suffixes, sequences, repeats, date-like values, and visibly separated phrases.

      Random-model upper bound

      The calculator infers the character classes present and estimates the average position in that complete search space. Human-chosen values rarely behave like uniform random samples.

      Classical time

      Estimated average guesses are divided by a selected illustrative rate. Real results depend on the exact verifier, hardware, software, optimization, and attack budget.

      Quantum query proxy

      The displayed Grover value is the square root of the random-model average search work. No seconds are shown because oracle depth, error correction, hardware, and serial query costs are not modeled.
