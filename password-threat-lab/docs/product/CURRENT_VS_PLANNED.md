# Current vs. Planned

## Current candidate

- Static GitHub Pages-compatible surface.
- Local-only input processing.
- Bounded pattern-aware estimator.
- Uniform random-space comparison.
- Illustrative classical attack profiles and custom rate.
- Grover random-space query proxy without a time prediction.
- Shor/PQC educational separation.
- Official primary-source links.
- Python reference model and local quality gate.
- N-stack contracts and evidence docs.

## Required before an MVP-ready review

- Draft PR exists at a known head SHA.
- Complete local quality gate passes at that head.
- Human review confirms privacy wording and visual usability.
- Mobile and keyboard navigation are reviewed.
- Parent repository discovery link is accepted or intentionally omitted.
- Review findings are closed or explicitly deferred.
- Owner separately authorizes any MVP-ready claim.

## Planned after initial review

- Improve pattern coverage only with tests that demonstrate reduced false confidence.
- Add a benchmark metadata import format that requires hash, parameters, hardware, software, and date.
- Add automated accessibility checks in a governed development environment.
- Add a root-site navigation entry in a separate scoped patch if the owner approves.
